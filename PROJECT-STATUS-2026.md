# ALIEN XBOX — Project status

Active development ended in November 2026 at the author's request.

Last device-tested experimental baseline: V86.1. Reported guest instructions: 186,243,436; static imports bound: 265 of 587; unresolved: 322. Graphics initialization attempts: zero. Immediate blocker: missing xgameruntime.dll, followed by a guest breakpoint. No commercial game playability is claimed.

Experimental work includes x86-64 interpretation, ARM64 execution, PE loading and relocation, restricted dynamic DLL linking, CRT bindings and partial AMD64 unwinding. Full exception handling, DLL initialization and TLS remain incomplete.
