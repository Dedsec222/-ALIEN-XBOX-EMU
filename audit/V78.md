# ALIEN XBOX V78 engineering results

## CPU

The reference path is executeGuest64 in scarlett_cpu64.hpp. The Android picker streams authorized AMD64 PE files into private storage, validates their headers and maps their input read-only for execution. The bundled Alien Doors game keeps its interactive ABI. The Scarlett diagnostic runs a three-instruction homebrew test with the exact reported 0F CF encoding. A signed guest image was not available to reproduce RIP 0x140c635bc or identify the following blocker.

The BSWAP implementation covers all sixteen 32-bit and 64-bit register destinations. MOVBE supports 16/32/64-bit memory transfers in both directions using the existing ModRM/SIB addressing decoder. Tests cover 32 BSWAP forms, flags and register width, MOVBE faults, 72 packed integer min/max forms and 48 horizontal integer arithmetic and multiply forms. Legacy forms retain upper YMM state. VEX.128 clears it. The fence family uses an explicit host ordering fence. Guest threads still run serially. Adding parallel guest CPUs would require a shared memory model for every interpreter and translated access, including misaligned and cross-page locked operations.

cpu.csv lists every mnemonic and static count in the supplied workload report. Its last two columns come from decoding instructions retired by the synthetic and homebrew tests. A distinct byte string is one encoding. Matching uses Capstone AT&T mnemonics. Aliases or spelling differences can undercount. Synthetic coverage establishes selected operand behavior only. The project still lacks full x87/MXCSR exception behavior, full prefix handling, complete legacy SSE/SSE2/SSE3/SSE4, AVX/AVX2/FMA3/BMI and architectural exception delivery. The static report includes padding and linear disassembly of unreachable regions. It contains no instruction addresses.

## Runtime and imports

imports.csv lists all 587 IAT slots from the user's earlier address-bearing ALIEN_IMPORTS.txt inventory. Every row was submitted to the actual V77 and V78 registries. Default and experimental bindings are separate. The source inventory uses display names for some Winsock ordinals. The runtime also supports the four network-order conversion ordinals. An unsupported row has no default binding. A partial row has a binding and a limited or unverified guest contract. The optional diagnostic output API reads its guest input and may emit a host trace. The implemented label is reserved for narrow reviewed contracts in the single-thread runtime.

V78 adds bounded, per-process binary scratch files. Open, close, flush, seek, tell, rewind, byte and bulk I/O share one backing per guest filename. Quotas are 8 MiB total file content, 256 flat filenames and 64 open streams. No installed title files, host paths or persistent save data are exposed. Text mode, Win32 OVERLAPPED I/O, directory traversal and device handles remain unavailable. User-mode UTC time conversion, stack limits, network byte order, nexttowardf and CRT time functions extend the runtime. Optional Xbox memory experiments remain disabled by default. Neither a CPU-side reservation nor an HLE address proves a GPU mapping or a complete service.

## ARM64

The optional ARM64 block compiler translates straight-line register-immediate MOV, register BSWAP and NOP. A bounded per-run cache checks the guest source bytes and execute permissions on reuse. Emitted pages transition from writable to executable. Compiled blocks leave guest branches, memory, flags, atomics and imports to the reference interpreter. It checks the budget and stop address before entering a block. Tracing selects the interpreter. Code-page denial falls back to interpretation. The Android settings page exposes the compiler as an opt-in. The default is the interpreter.

The backend test compares registers, flags, exit reason, RIP and step counts at varied budgets, an internal stop and after modifying cached code. The same test benchmarks both engines on a 100,000-instruction synthetic loop. Linux AArch64 under QEMU user-mode validates generated instructions and cache behavior. Its timings cannot predict Android performance.

FEX and Box64 are upstream userspace emulators. Integrating either requires a validated bridge for the PE/Xbox calling convention, memory faults, guest HLE callbacks, TLS, signals, self-modifying code, and Android executable memory. Neither is linked. The project's own scalar backend does not translate SSE to NEON. Packed min/max and horizontal operations have portable integer reference implementations suitable for differential testing of a future NEON path. Sparse backing already existed in V77. V78 accelerates instruction fetch with one execute-permission-aware page lookup and permits execute-only code. Android diagnostics report peak process RSS and system memory pressure. APK file ingestion uses bounded streaming and a read-only file mapping.

Upstream sources: https://github.com/FEX-Emu/FEX and https://github.com/ptitSeb/box64

## Graphics and assets

The import inventory contains D3D12XboxCreateDevice, D3D12SerializeVersionedRootSignature, D3D12ConfigureVirtualMemoryX and DStorageGetFactory. A full backend needs device/queue ABI dispatch, guest resource and descriptor lifetime tracking, command-list decoding and fence propagation. The Vulkan diagnostics exercise device and buffer allocation, command submission, a GPU-to-host barrier, fence completion and byte-for-byte readback. They report queue families, memory heaps and block-compressed texture support. The shader translator accepts a restricted SM4/5 tokenized pixel shader with a single float4 literal written to render target zero. It creates Vulkan 1.0 SPIR-V, and the probe constructs a shader module from it. Unknown instructions and linkage are unsupported. The probe does not draw a guest frame.

VKD3D-Proton's DXBC/DXIL to SPIR-V translation is relevant to compatible shader containers. The archive supplies no console shader corpus, command packets, root-signature fixtures, compressed asset samples or read/decompress request traces. Xbox-specific shader translation, DirectStorage formats, streaming scheduling and Adreno 830 driver behavior remain unverified. Texture format support does not identify an asset archive codec.

Upstream source: https://github.com/HansKristian-Work/vkd3d-proton

## Running on Termux

Install clang and git, then use the development branch. From the repo root:

```sh
pkg install git clang
CXX=clang++ JOBS=2 bash tools/regression.sh
clang++ -O2 -std=c++20 -Iapp/src/main/cpp tests/scarlett_import_entry_test.cpp -o alien-trace
./alien-trace /path/to/authorized.exe
```

For a short sample use ALIEN_BLOCK_TRACE=1 or ALIEN_INSN_TRACE=1 and redirect stderr. ALIEN_OPCODE_TRACE=1 captures pre-execution bytes on retirement. High-volume tracing is intended for bounded diagnostic runs. tools/alien_coverage.py summarizes instruction and block events. To regenerate the coverage matrix install Python Capstone, create an empty trace directory, set ALIEN_OPCODE_TRACE=1 and COVERAGE_DIR to its absolute path during regression, then run tools/coverage_matrix.py with the static report, trace directory and CSV destination.

Apply the supplied git patch only to the matching V77 source tree. From its root, run git apply --check /path/to/ALIEN_V78.patch before git apply /path/to/ALIEN_V78.patch. The complete archive can be extracted in a separate empty directory instead.
